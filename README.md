# BioMed Hub — منصة الهندسة الطبية

الموقع + لوحة إدارة مبنية بلغة **Node.js** أو **Python** (خيارك) مع حماية مدمجة.

## التشغيل

### الخيار 1: Node.js (موصى به — بدون مكتبات خارجية)
```bash
node server.js
```
افتح: **http://localhost:8080** — لوحة الإدارة: **http://localhost:8080/admin.html** — البث المباشر: **http://localhost:8080/live.html**

> ملاحظة: البث المباشر وتخزين التسجيلات يعملان مع خادم Node.js. خادم Python (`server.py`) يدعم الموقع واللوحة فقط.

### الخيار 2: Python
```bash
pip install -r requirements.txt
python server.py
```
افتح: **http://localhost:5000** — لوحة الإدارة: **http://localhost:5000/admin.html**

> إن كان المنفذ مشغولاً غيّره بسيطاً:
> `PORT=4000 node server.js` (لـNode) أو عدل `port` في `server.py`.

## البث المباشر (بأسلوب ميت)
- **يبدأه الأدمن فقط** من اللوحة عبر زر "فتح استوديو البث" (كلمة مرور الأدمن مطلوبة).
- يدعم: بث الشاشة أو الكاميرا أو **الشاشة + الكاميرا** (معاينة الوجه داخل البث).
- **للأدمن**: كتم/رفع كتم المايك، إيقاف الكاميرا، كتم جميع الحاضرين، فتح/إغلاق التعليقات، حذف أي تعليق، الطرد، وإيقاف أي مشاهد عن الكلام.
- **للزوار**: تعليقات لحظية، رفع اليد للطلب بالتحدث، تشغيل المايك (صوته يصل للأدمن فقط)، ومشاهدة البث لحظياً بتأخير منخفض (WebRTC).
- **التسجيل**: زر تسجيل في الاستوديو — يُسجَّل البث من متصفح الأدمن ويُحفظ على هيئة مقاطع داخل مجلد `recordings/`، ويظهر في "تسجيلات البث" باللوحة مع تشغيل وحذف، ويُشغَّل من رابط مباشر (`/recordings/<file>.webm`).
- عند بدء البث يظهر شعار **"مباشر الآن"** في الموقع الرئيسي ويدخل الزوار للبث مباشرة.

> ملاحظة تقنية: البث يوزَّع عبر WebRTC مباشرة من متصفح الأدمن (تأخير منخفض جداً) ويلائم مئات المشاهدين. للوصول لـ **2000+ مشاهد** بنفس التجربة، استضف المنصة خلف CDN (مثل Cloudflare مجاناً) أو اربط لاحقاً خادم وسائط (LiveKit) — البنية جاهزة لتبديل طبقة التوزيع دون تغيير الواجهة.

## الحماية المدمجة
- ✅ محدة معدل الطلبات (Rate Limiting) ضد DDoS — 100 طلب/دقيقة للـIP
- ✅ منع حقن XSS في الإدخالات
- ✅ رفض Path Traversal في الملفات
- ✅ جلسات تسجيل دخول للـAdmin برمز توكن
- ✅ رؤوس أمنية (X-Frame-Options DENY, nosniff, Referrer-Policy)
- ✅ فحص وتحقق صارم من وسوم HTML في النصوص

> ملاحظة: للحماية من DDoS الكامل على الإنترنت استضف الموقع خلف Cloudflare (مجاني) وأشفّر الاتصال بـ HTTPS.
